# Codex Structured Skills Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make Codex skills available as `$skill` suggestions in the Vibe editor and submit selected skills to Codex as structured `UserInput::Skill` entries with name and path.

**Architecture:** Backend discovery exposes Codex skill metadata separately from slash commands. The editor keeps selected skill metadata alongside the markdown text, and session create/follow-up payloads carry that metadata to the executor. Only the Codex executor consumes structured skills; other executors keep their existing text-only behaviour.

**Tech Stack:** Rust, Axum, ts-rs generated shared types, React, TypeScript, Lexical, Codex app-server protocol.

- [ ] **Step 1: Expose discovered skills in the hook**

- [ ] **Step 2: Add selected skill state to the editor boundary**

Extend `WYSIWYGEditor` props with optional:

```ts
selectedSkills?: SelectedSkill[];
onSelectedSkillsChange?: (skills: SelectedSkill[]) => void;
```

The editor remains text-first. The extra state only changes when a skill is selected from typeahead or when selected skill text is removed.

- [ ] **Step 3: Create `$skill` typeahead**

Implement `SkillTypeaheadPlugin` parallel to `SlashCommandTypeaheadPlugin`:

```ts
triggerFn={(text) => {
  const match = /^(\s*)\$([^\s$]*)$/.exec(text);
  if (!match) return null;
  return {
    leadOffset: match[1].length,
    matchingString: match[2],
    replaceableString: match[0].slice(match[1].length),
  };
}}
```

Filter enabled skills by name first, then includes. Show `$name`, description, and scope. On select, insert `$name ` as visible text and call `onSelectedSkillsChange()` with `{ name, path }` if not already selected.

- [ ] **Step 4: Prune stale selected skills**

When editor text changes, remove a selected skill if its `$name` no longer appears in the text. This keeps accidental deleted mentions from being submitted.

- [ ] **Step 5: Carry selected skills through send**

Change send APIs to accept:

```ts
send(message: string, selectedSkills?: SelectedSkill[])
```

Include `selected_skills` in both create session and follow-up bodies.
